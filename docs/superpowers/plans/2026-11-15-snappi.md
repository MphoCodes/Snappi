# Snappi Implementation Plan

Goal: deliver a native photo/video camera using approved Daylight branding, free local effects and on-device media storage.
Architecture: AVFoundation capture on a serial queue, Core Image effects shared by preview/photo/video export, SwiftUI controls and local gallery. Photos add-only access is optional. No accounts, analytics, server or purchases.
Tech stack: Swift 5, SwiftUI, AVFoundation, Core Image, Photos, iOS 17+.
Spec: user-approved camera + video direction and HANDOFF.md branding; direct implementation requested.
